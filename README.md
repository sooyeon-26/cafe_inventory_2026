# Cafe Inventory

카페 재고 확인부터 발주 준비까지 한 화면에서 이어지는 데스크탑 중심 워크스페이스입니다. React + Vite로 만든 프론트엔드 데모이며 서버나 API 키 없이 실행할 수 있습니다.

## 실행

Node.js 22 이상을 권장합니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소(기본 `http://127.0.0.1:5173`)를 엽니다.

```sh
npm run build
npm run preview
```

`dist/`를 정적 호스팅에 배포할 수 있습니다. 상대 에셋 경로를 사용하므로 하위 경로에도 배포할 수 있습니다. 자동 배포와 원격 Git 저장소는 설정되어 있지 않습니다.

## 기능

- 품목 탐색, 이름·카테고리·단위 검색, 재고 상태 필터
- 품목 등록·수정·삭제와 재고 수량 직접 입력 및 +/- 조정
- 현재·최소·적정 재고 비교, 권장 발주량 실시간 계산
- 발주 목록 추가, 중복 방지, 수량 조정, 제거
- 데모 발주 생성과 재고/품목 변경 이력
- 1440px·1280px 3영역 배치, 1100px 이하에서 발주 목록 drawer
- 키보드 포커스, 모달 포커스 관리, 동작 줄이기 설정 지원

## 데이터와 발주 기준

최초 방문에만 `src/data.js`의 목업 품목 10개를 사용합니다. 재고·품목·발주 목록·이력은 `localStorage`의 `cafe-inventory:v1`에 저장되며 새로고침 후 복원됩니다. 저장된 빈 품목 목록도 유지합니다. 유효하지 않은 기존 데이터는 덮어쓰지 않고 오류를 안내합니다.

| 조건                                                | 상태      |
| --------------------------------------------------- | --------- |
| 현재 재고 ≥ 최소 재고                               | 정상      |
| 최소 재고의 절반 < 현재 재고 < 최소 재고            | 발주 필요 |
| 현재 재고 ≤ 최소 재고의 절반, 현재 재고 < 최소 재고 | 긴급      |

권장 발주량은 `max(적정 재고 - 현재 재고, 0)`입니다. 발주 필요 필터에는 긴급 품목도 포함됩니다. 재고 범위 표시는 최소 이하/적정 미만/적정 이상을 구분합니다. 최소 재고 경계에서 정상 상태라도 범위는 주의 색상을 사용합니다.

중복 추가 시 사용자가 조정한 발주 수량을 보존합니다. 발주는 목록을 비우고 이력에 기록하지만 입고를 의미하지 않으므로 현재 재고를 변경하지 않습니다. 실제 공급업체에 주문을 전송하지 않습니다. 수량은 0~999,999의 정수, 발주 수량은 1 이상이며 적정 재고는 최소 재고 이상입니다.

데이터는 해당 브라우저와 주소에만 저장됩니다. 다른 기기와 동기화되지 않으며 브라우저 데이터를 삭제하면 없어집니다. 여러 탭의 동시 편집은 지원하지 않습니다. 웹폰트(DM Sans, Noto Sans KR)는 Google Fonts에서 불러오고 연결할 수 없는 경우 시스템 글꼴을 사용합니다.

## 테스트

```sh
npm test
npx playwright install chromium
npm run test:e2e
```

단위 테스트는 계산 경계값, 검색·필터, 품목/발주 처리, 저장 데이터 검증을 확인합니다. 브라우저 테스트는 품목 CRUD, 재고 조정, 발주 생성, 새로고침 후 복원, 손상 데이터 보호 및 1440/1280/1024px 레이아웃을 확인합니다. 스크린샷과 실패 기록은 Git에서 제외되는 `test-results/`에 저장됩니다.

## 구조

- `src/App.jsx`: 화면 상태와 컴포넌트 연결
- `src/components/`: 품목 탐색, 상세·재고 범위, 발주 목록, 폼·이력
- `src/inventory.js`: 재고·발주 계산, 데이터 검증, 상태 변경
- `src/useInventory.js`: 저장과 복원
- `src/data.js`: 최초 목업 데이터
- `src/styles.css`: 데스크탑 레이아웃, 상태 스타일, 반응형 처리
- `tests/`: 단위 및 Playwright 브라우저 테스트
